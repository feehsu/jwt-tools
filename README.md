# 🛠️ JWT Interactive Studio Pro

Uma ferramenta web simples, rápida e interativa para decodificar, editar, assinar e comparar tokens **JWT (JSON Web Tokens)** diretamente no navegador.

---

## 🚀 Acesse Agora

A aplicação está hospedada e pronta para uso no GitHub Pages:

👉 **[https://feehsu.github.io/jwt-tools/](https://feehsu.github.io/jwt-tools/)**

---

## ✨ Funcionalidades

* **Decodificador & Encodador de JWT:** Cole o token para decodificar ou edite o payload para gerar um novo token.
* **Assinatura HMAC-SHA256:** Suporte a chaves secretas para validação e geração de assinaturas.
* **Modo Interactive (Pretty):** Edição visual de campos e arrays sem precisar formatar JSON manualmente.
* **Gerenciador de Claims Temporais:** Manipulação simplificada de datas (`iat`, `exp`, `nbf`) via seletores de data/hora.
* **Comparador de Tokens:** Compare dois JWTs lado a lado com destaque visual (*highlight*) automático para diferenças no payload.
